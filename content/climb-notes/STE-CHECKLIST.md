## 1. Sentence limits

| Rule | Limit |
| --- | --- |
| Max words per sentence | **20** (soft); **25** hard stop |
| Max clauses | Prefer **1** main idea; max **2** with a simple connector (and / but / so) |
| Max sentences — Base Camp | **5** |
| Max sentences — Route | **3** |
| Max sentences — Waypoint | **4** (or one short numbered list ≤ 5 lines) |
| Max sentences — Summit | **3** |
| Title | ≤ **12** words |

**Check:** Read each sentence out loud. If you need a breath mid-sentence, split it.

## 2. Approved verb list (starter)

Use these first. Prefer **present** or **simple past**. One verb meaning per sentence when possible.

### Core action verbs

`start` · `stop` · `open` · `close` · `write` · `read` · `see` · `show` · `name` · `use` · `make` · `build` · `ship` · `publish` · `save` · `set` · `get` · `keep` · `find` · `fix` · `check` · `prove` · `finish` · `try` · `learn` · `help` · `need` · `know` · `say` · `follow` · `choose` · `add` · `remove` · `change` · `move` · `run` · `hold` · `carry` · `turn` · `collect` · `define` · `plan` · `do` · `leave` · `recover` · `decide`

### Climb Notes verbs (allowed product terms)

`climb` · `write down` · `waypoint` · `hold` · `go` · `summit`

Legacy `problem` / `measure` / `pitch` / `slice` / `lesson` still **read** as headings. Do not write them as headings on new public notes.

### Prefer not (public)

| Avoid | Prefer |
| --- | --- |
| leverage | use |
| utilize | use |
| facilitate | help |
| implement | build / do / ship |
| optimize | make better / improve |
| compound *(non-finance)* | get better over time |
| navigate *(metaphor stack)* | find / follow / get lost |
| solution / solutioning | solve / fix / answer |
| operationalize | put into use / run |
| ideate | think / invent / plan |
| unlock | open / enable / make possible |

Add new verbs only when plain English cannot say the same thing. Log them in the glossary table below.

## 3. Term glossary (public)

### Prefer these words

| Term | Meaning (plain) | Notes |
| --- | --- | --- |
| **Climb Note** | A short written record of one climb | Product name; always capital C + N |
| **climb** | The work from Base Camp to Summit | Lowercase when general |
| **Base Camp** | Are we fit to leave? | Gear, weather, rules, who we are |
| **Route** | One summit objective | Success marks + what we are not climbing today |
| **Waypoint** | Check the map; hold or go | Stop, look around, recover if needed |
| **Summit** | Build, prove, evidence home | Not just a story of the attempt |
| **mountain first, kit second** | Name the peak before the tools | Locked product line; allowed as-is |
| **Sherpa** | Luna walks with you | She does not carry you or replace judgment |
| **agent** | Who acts on the write-up | Unifying term. Luna stays Sherpa. |
| **quietly / actually / quickly** | *(cut)* | Orwell: drop the -ly |
| **“not X, it’s Y”** | say the thing | Joe Wyer stop-reading trigger |
| **path / trail** | Order of steps people can follow | Light metaphor |
| **tools** | Models, apps, prompts, platforms | List only when needed |
| **public** | Anyone can read on the site | vs studio-only |
| **X** | The public short post | Full detail stays on site |

### Avoid or replace (public)

| Term | Replace with |
| --- | --- |
| tool raft | many tools / pile of tools |
| stack *(metaphor)* | many tools / list of tools |
| free solo | work without a written plan |
| MacroFlow | how the climb runs / Base Camp → Route → Waypoint → Summit |
| Constitution / Clarify / Workforce | Base Camp / Route / Summit *(public only)* |
| Problem / Measure / Pitch / Slice / Lesson *(as move names)* | Base Camp / Route / Waypoint / Summit |
| characterization | *(delete — use title + four beats)* |
| GTM / ADO / etc. | spell out or omit on public notes unless the note is about that system |
| vertical / thin vertical | small finished step |
| SoT / source of truth | main note / first public note *(or define once)* |

### Allowed product names (no expansion required)

`Climb Notes` · `Acornsoft` · `Canopy` · `Gnomah` · `Luna` · `X` · `Luna Foundry Multiagent`

First mention of a rare product: one short plain phrase, then the name.

## 4. Grammar & style (STE-like)

- [ ] **Active voice** by default (“We publish the note”).
- [ ] **Articles** present where English needs them (*a* / *the*).
- [ ] **No noun stacks** of 3+ (*enterprise AI agent orchestration platform* → break up).
- [ ] **No slang or idioms** that fail outside US tech (*boil the ocean*, *move the needle*).
- [ ] **No humor that hides the evidence.**
- [ ] **Commands OK in Waypoint** (“Check the map. Hold or go.”).
- [ ] **Consistent terms** inside one note (pick the four beat names; do not mix in Problem/Lesson).
- [ ] **Numbers as digits** for measures (`5 seconds`, `1 team`).

### Length
- [ ] No sentence over 25 words  
- [ ] Base Camp ≤ 5 sentences · Route ≤ 3 · Waypoint ≤ 4 · Summit ≤ 3  
- [ ] Title ≤ 12 words  

### Words
- [ ] Verbs from approved list (or noted exception below)  
- [ ] No leverage / utilize / solutioning / compound / raft / stack metaphor pile  
- [ ] **Fit to leave** named when Base Camp is about starting  
- [ ] Glossary terms used consistently  

### Structure
- [ ] Only headings: Base Camp · Route · Waypoint · Summit  
- [ ] Route success marks are checkable by a stranger  
- [ ] Waypoint is hold or go, not the whole build  
- [ ] Summit brings evidence home  

### Read-aloud
- [ ] Read Base Camp out loud — no stumble  
- [ ] Read Summit out loud — one clear proof
