## 1. Sentence limits

| Rule | Limit |
| --- | --- |
| Max words per sentence | **20** (soft); **25** hard stop |
| Max clauses | Prefer **1** main idea; max **2** with a simple connector (and / but / so) |
| Max sentences — Problem | **5** |
| Max sentences — Measure | **3** |
| Max sentences — Slice | **4** (or one short numbered list ≤ 5 lines) |
| Max sentences — Lesson | **3** |
| Title | ≤ **12** words |

**Check:** Read each sentence out loud. If you need a breath mid-sentence, split it.

## 2. Approved verb list (starter)

Use these first. Prefer **present** or **simple past**. One verb meaning per sentence when possible.

### Core action verbs

`start` · `stop` · `open` · `close` · `write` · `read` · `see` · `show` · `name` · `use` · `make` · `build` · `ship` · `publish` · `save` · `set` · `get` · `keep` · `find` · `fix` · `check` · `measure` · `finish` · `try` · `learn` · `help` · `need` · `know` · `say` · `follow` · `choose` · `add` · `remove` · `change` · `move` · `run` · `hold` · `carry` · `turn` · `collect` · `define` · `plan` · `do`

### Climb Notes verbs (allowed product terms)

`climb` · `write down` · `step` · `slice` (as verb: “slice the work”) — use sparingly; prefer “small next step” in public prose.

### Prefer not (public)

| Avoid | Prefer |
| --- | --- |
| leverage | use |
| utilize | use |
| facilitate | help |
| implement | build / do / ship |
| optimize | make better / improve |
| compound *(non-finance)* | get better over time |
| navigate *(metaphor stack)* | find / follow / get lost |
| solution / solutioning | solve / fix / answer |
| operationalize | put into use / run |
| ideate | think / invent / plan |
| unlock | open / enable / make possible |

Add new verbs only when plain English cannot say the same thing. Log them in the glossary table below.

## 3. Term glossary (public)

### Prefer these words

| Term | Meaning (plain) | Notes |
| --- | --- | --- |
| **Climb Note** | A short written record of one climb | Product name; always capital C + N |
| **climb** | The work from problem to lesson | Lowercase when general |
| **problem** | What is stuck | Prefer **clearly defined problem** |
| **measure** | How we know progress happened | Observable check |
| **slice** | The small next step we finish | Prefer “small next step” once in a note if “slice” feels insider |
| **lesson** | What we keep for the next climb | Reusable |
| **path / trail** | Order of steps people can follow | Light metaphor |
| **tools** | Models, apps, prompts, platforms | List only when needed |
| **public** | Anyone can read on the site | vs studio-only |
| **X** | The public short post | Full detail stays on site |

### Avoid or replace (public)

| Term | Replace with |
| --- | --- |
| tool raft | many tools / pile of tools |
| stack *(metaphor)* | many tools / list of tools |
| free solo | work without a written plan |
| MacroFlow | how the climb runs / four steps |
| characterization | *(delete — use title + four steps)* |
| GTM / ADO / etc. | spell out or omit on public notes unless the note is about that system |
| vertical / thin vertical | small finished step |
| SoT / source of truth | main note / first public note *(or define once)* |

### Allowed product names (no expansion required)

`Climb Notes` · `Acornsoft` · `Canopy` · `Gnomah` · `Luna` · `X`  

First mention of a rare product: one short plain phrase, then the name.

## 4. Grammar & style (STE-like)

- [ ] **Active voice** by default (“We publish the note”).
- [ ] **Articles** present where English needs them (*a* / *the*).
- [ ] **No noun stacks** of 3+ (*enterprise AI agent orchestration platform* → break up).
- [ ] **No slang or idioms** that fail outside US tech (*boil the ocean*, *move the needle*).
- [ ] **No humor that hides the measure.**
- [ ] **Commands OK in Slice** (“Name one problem. Write the measure.”).
- [ ] **Consistent terms** inside one note (pick *problem* or *stuck state*, not both randomly).
- [ ] **Numbers as digits** for measures (`5 seconds`, `1 team`).
